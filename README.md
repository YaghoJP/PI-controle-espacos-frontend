# PI — Controle de Espaços (Frontend)

Repositório destinado ao **frontend** do projeto de PI.  
O sistema é um **site de reservas de ambientes**, onde é possível acessar como **usuário cliente** ou **administrador**, cada um com suas próprias funcionalidades.

---

## Tecnologias utilizadas

- **Next.js**
- **Docker**

---

## Funcionalidades principais

- Acesso como **cliente** para solicitar reservas.
- Acesso como **administrador** para gerenciar ambientes e aprovar/recusar solicitações.
- Interface simples, intuitiva e responsiva.

---

## Como rodar o projeto

1. **Clonar o repositório**
2. Na raiz do projeto, executar:

   ```bash
   docker-compose up --build
3. Acessar no navegador:
http://localhost:3000
